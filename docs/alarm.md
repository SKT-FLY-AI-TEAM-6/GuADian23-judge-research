#### HIGH 반복 알림 규칙

같은 host의 위험 사건이 반복되면 새 알림 줄을 계속 만들지 않고 반복 행동 자체를 알려주는 요약 알림을 한 번 추가로 발송

알림 예시

1회

> ⛔ 위험한 사이트 접속을 차단했어요  
> badsite.com으로의 위험한 접속을 막았습니다.

2회

> ⛔ 위험한 사이트 접속을 차단했어요 · 2번

3회

> ⛔ 위험한 사이트 접속을 차단했어요 · 3번

그리고 최근 1시간 내 같은 host에서 위험 사건이 반복 발생하면 반복 행동 자체를 알려주는 요약 알림을 한 번 추가로 발송

반복 접근 요약 알림 예시

> 📋 같은 위험 사이트 접근이 반복되고 있어요  
>
> ○○님이 최근 한 시간 동안 같은 위험 사이트에 여러 번 접근했습니다.  
>
> 총 4회 · GuADian이 모두 차단했어요  
>
> 눌러서 자세히 확인해 주세요.

| 9 | 착지한 페이지가 주의 판정된 뒤 ‘그래도 보기’ 선택 (새로 발견사이트) | 페이지 이동 후 | [AdDetectService.kt:437](../app/src/main/java/com/flyai/adalert/AdDetectService.kt#L437) (:1522 연계) | 주의가 필요한 사이트에 접속했어요 한 번 확인해 주세요. | 30초 |

#### MEDIUM 반복 알림 규칙

동일 host에서 24시간 내 그래도 보기가 반복되면 동일한 푸시는 다시 보내지 않고 기존 알림의 횟수만 증가

알림 예시

> ⚠️ 주의 안내 후에도 사이트 접속을 시도했어요 · 3번

단, 최근 1시간 내 같은 host에서 반복 접근이 4회째 발생하면 「같은 주의 사이트 이용이 반복되고 있어요」 형태의 요약 알림을 1회 보내고 이후 발생 건은 해당 요약 알림의 횟수에 누적

반복 접근 요약 알림 예시

> 📋 주의 사이트 이용이 반복되고 있어요  
>
> ○○님이 같은 사이트에서 주의 안내를 여러 번 확인했지만 계속 이용했습니다.  
>
> 최근 한 시간 동안 4회  
>
> 필요하면 함께 확인해 주세요.

### 3. 알림 규칙

| 항목 | 알림 기준 | 현재 최종 알림 형태 |
| :-- | :-- | :-- |
| LOW 일반 광고 | 보호자 알림 X | 기록도 알림도 X |
| MEDIUM 주의 광고 | ‘그래도 보기’를 눌렀을 때만 보호자 알림 | ⚠️ 주의가 필요한 사이트에 접속했어요 |
| HIGH 위험 광고/도메인 | 즉시 알림 | ⛔ 위험한 사이트 접속을 막았습니다 |
| HIGH 위험 검색 (웹 검색) | 즉시 알림 | ⛔ 위험한 사이트 접속을 막았습니다 |
| APK 설치 위험 | 즉시 알림 | ⛔ APK 설치를 막았습니다 |
| MEDIUM 반복 | 동일 host 24시간 내 푸시 1회, 기록은 누적 | 반복은 새 줄 없이 숫자 증가 |
| HIGH 반복 | 발생 자체는 중요하지만 중복 푸시 관리 필요 | 같은 종류 반복은 숫자로 누적 |
| 알림 폭주 | 알림 피로 방지 필요 | 시간당 3건 초과 시 요약 |
